# Auto Installer App By Danny

## 1. Introduction

Auto Installer is a Windows application that allows users to install multiple software packages with just a single click, eliminating the need to manually download and configure each application individually.

The project is developed in *Python* and uses the *PySide6* framework to deliver a modern, responsive, and highly customizable user interface. By using *PySide6*, the application can support various UI patterns and components while maintaining a clean and user-friendly experience.

The main goal of this project is to simplify the software setup process, reduce installation time, and provide a centralized platform for managing application installations.
